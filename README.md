# Security Field Notes

**Cybersecurity | Systems | Security Investigations**

## About This Portfolio

This repository documents hands-on cybersecurity exercises, system investigations, and technical projects. Each case study focuses on the methods used, evidence collected, findings identified, and practical recommendations.

My goal is to develop and demonstrate skills across security operations, IT support, systems administration, and security assessment.

### 01 — Windows System & Security Investigation

### 02 — Phishing Triage
*Status: Planned*

### 03 — Blue-Team Investigation
*Status: Planned*

Completing a guided security investigation and documenting the analysis, findings, and remediation recommendations.

## Approach

- Document the investigation process, not just the final answer.
- Distinguish observed evidence from assumptions.
- Explain technical findings in plain language.
- Prioritize practical, actionable recommendations.
- Use authorized training environments and sanitize sensitive information.
